# Private reference files

Die fachliche Referenz-Exceldatei und andere nicht für GitHub bestimmte Dateien werden lokal unter `reference/private/` abgelegt.

Empfohlener lokaler Pfad:

```text
reference/private/Aktien Bewertungs Tool.xlsm
```

`reference/private/` ist in `.gitignore` eingetragen. Die Excel-Datei bleibt damit lokal und wird nicht in das öffentliche Repository hochgeladen.

Für Phase 1 darf Codex diese lokale Datei analysieren, wenn sie vorhanden ist. Die daraus abgeleiteten Formeln, Felddefinitionen und Mapping-Dokumente dürfen anschließend als **eigene technische Dokumentation** in das Repository übernommen werden. Buchtext selbst wird nicht kopiert.
